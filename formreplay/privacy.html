FormReplay Privacy Policy

Last updated: August 24, 2026

FormReplay is designed to keep form contents on the user's device.

Data FormReplay accesses

When the user explicitly clicks Save form or Fill, FormReplay accesses supported form controls on the active web page so it can save or restore the user's chosen form profile. It does not continuously monitor browsing activity.

FormReplay intentionally excludes password fields and fields identified as payment-card details, PINs, one-time passwords, two-factor or multi-factor authentication codes, and verification or security codes.

Storage

Saved form profiles are stored locally using the Chrome extension storage API. A profile can include the page URL, origin, page title, field labels and matching information, and the values of supported fields the user chose to save. FormReplay does not operate a server that receives or stores saved form contents.

Payments and license activation

FormReplay offers an optional one-time Pro license through Gumroad. When a user chooses to activate a license, the provided license key and FormReplay's Gumroad product identifier are sent to Gumroad's HTTPS license-verification endpoint. The returned license status is stored locally. Saved form contents are not included in that request.

Gumroad processes that request under its own privacy terms.

Analytics and advertising

FormReplay contains no advertising SDKs, analytics SDKs, or behavioral tracking.

Data sharing or sale

FormReplay does not sell saved form data. FormReplay does not transfer saved form contents to third parties.

FormReplay's use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Deletion

Users can delete individual saved profiles from the extension. Removing the extension also removes its locally stored extension data according to Chrome's platform behavior.

Contact

For privacy questions, use the contact page.
